# Portfolio Site for M R Shihab

This site is inspired by paul.kinlan.me and built with HTML, CSS, and JS.

## Deployment: GitHub Pages

1. Push this code to a GitHub repository (e.g., `mrshihab.github.io` or any repo).
2. In the repository settings, enable GitHub Pages:
   - Set the source to the `main` branch (or `gh-pages` if you use a separate branch).
   - Set the folder to `/ (root)`.
3. Your site will be live at `https://<your-github-username>.github.io/` or at the custom domain if configured.

## Custom Domain

1. In the GitHub Pages settings, set your custom domain to `www.mrshihab.com`.
2. Add a `CNAME` file to the root of your repository with this content:

    www.mrshihab.com

3. Update your domain DNS settings:
   - Add a CNAME record for `www` pointing to `<your-github-username>.github.io`.
